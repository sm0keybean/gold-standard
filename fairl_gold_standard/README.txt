GETTING STARTED
Enable Gold Standard for your game and open the gold GS coin-seal toolbar button. Choose a preset or Create your own. Set the conversion rate, monetary base year, annual display inflation/deflation, decimals, grouping and label position. Select Apply to this save, then save your game to retain the settings.

USING OTHER CURRENCIES
Japanese yen is a preset. Custom examples: ¥ / JPY, ₩ / KRW, ₽ / RUB, florin ƒ and franc ₣. Labels support 1–12 Unicode characters. Choose 0 decimal places for whole units if desired. Use letter codes if the game font cannot display a symbol. Rates are user-defined, not live exchange rates or verified historical conversions.

DISPLAY BOUNDARIES
The mod changes supported displays, not balances, costs or economic difficulty. The game economy continues independently. Historical finance rows use the current year's conversion.
Native construction/floating values and the save-selection balance remain in game dollars. The experimental native-label option changes only labels. Sandbox/account inputs remain in game dollars. Cached labels may require a panel reopen. Disabling requires a full restart; retained application currency-prefix settings may also need restoration.
Other currency mods or custom/native formatters can conflict or need integration. Long labels and high precision may exceed narrow fields in other mods. See the full README for compatibility details and contributor guidance.
